# <img src="images/VRCX.png" width="64" height="64" alt="VRCXF"> VRCXF

VRCXF は、VRChat のフレンド・ワールド・アバターを VRChat クライアントより便利に管理できるアシスタントアプリ [VRCX](https://github.com/vrcx-team/VRCX) のフォークです。
本家の機能を継承しつつ、Browser 版・ポップアウト・Google Drive バックアップなどの独自機能を加え、[AariyJP](https://github.com/AariyJP) が保守しています。

対応プラットフォーム: **Windows** / **macOS** / **Linux** / **Web ブラウザ**

## ✨ フォーク独自の機能

### 🌐 Browser 版

- インストール不要で、一般的な Web ブラウザから利用できます
- VRChat REST は同一オリジン経由で中継し、WebSocket は pipeline へ直接接続します
- データベースや Cookie はブラウザ側（IndexedDB など）に保存します
- Google Drive へのデータベースバックアップにも対応しています
- ゲームログ監視・Discord Rich Presence・VR オーバーレイなど、ネイティブ依存の機能は利用できません

### 🪟 ポップアウト

- ナビゲーションやメニュー項目の中クリックで、ビューやダイアログを別ウィンドウに切り離して並べられます
- ツールのダイアログもポップアウトできます
- Esc キーでポップアウトしたウィンドウを閉じられます
- 設定からの有効化が必要です（デスクトップ版のみ。Browser 版では無効）

### 🔔 通知・フィード

- **通知フィルタ「Everyone w/o Public/Group」** — Public と Group 系（Group / Group+ / Group Public）インスタンスではフレンドのみ、それ以外のインスタンスでは全員から入退室通知を受け取れます。デスクトップ通知と VR オーバーレイの共有フィードの両方で使えます
- **ゲームログの順番処理** — 同じ秒に届いた入退室ログを順番に処理し、インスタンス移動直後に VR 通知が一斉に出る問題を防ぎます
- **フィードの無効化** — フィード収集とデータベースへの書き込みを止めて軽量化できます。フィード画面から直接切り替えられます
- ログイン・ログアウト時のあいさつ通知を廃止しています

### 🎮 Discord Rich Presence

- ステータスバーに Discord との接続状態を表示し、ワンクリックで切り替えられます（Browser 版では利用不可）
- プレイ時間の表示にオフセットを設定できます
- Online ステータスの表示に対応し、Discord 再接続後にプレゼンスを再送します
- ボタンのリンクにプロフィール URL を使います

### 💾 データ管理

- **Google Drive バックアップ** — データベースを Google Drive のアプリ専用領域にバックアップし、そこから復元できます（デスクトップ版・Browser 版）
- **データベースのインポート** — 既存の VRCX データベースを取り込めます。取り込み前に SQLite として正しいファイルかを検査します
- **診断コンソール** — アプリ内に DevTools 相当のコンソールを内蔵しています（全プラットフォーム。ログはメモリ内のみで永続化しません）

### 🧭 画面・操作

- **フレンドロケーションの刷新（ソーシャル機能）** — カード表示、滞在時間、移動中（traveling）状態の可視化、インスタンス操作ボタンの拡充
- **WebSocket オフラインモード** — VRChat の WebSocket 接続を切った状態（オフライン表示のまま）でも利用できます。ステータスバーから切り替えられます
- **モバイル対応** — 狭い画面でもレイアウトが崩れないよう、ナビゲーション・テーブル・タブ・ページネーションをレスポンシブ化しています
- **年齢認証ステータスの変更** — プロフィール編集から自分の公開設定を切り替えられます
- **rednight テーマ** — フォーク追加のテーマで、初期テーマとしても使われます
- 🇯🇵 日本語ユーザー向けの細かな調整

## 🧰 主な機能（本家より継承）

- 👪 **フレンド管理** — オンライン状況・所在・アバターの監視、初回フレンド登録日・一緒に過ごした時間・名前変更履歴、メモ
- 📍 **フレンドロケーション（ソーシャル機能） / サイドバー** — フレンドのワールド・インスタンス一覧
- 📰 **フィード** — フレンド関連イベントのライブ／履歴
- 📜 **ゲームログ** — 入退室・動画再生などクライアントログの記録・閲覧
- 🧑‍🤝‍🧑 **プレイヤーリスト** — 現在インスタンスの統計・参加者一覧
- 🔍 **検索 / Quick Search** — ユーザー・ワールド・アバター・グループの検索、ID・URL の直開き、クライアント側ファジー検索
- ⭐ **お気に入り** — フレンド・ワールド・アバター（ローカル無制限のワールドお気に入りを含む）
- 🎭 **マイアバター** — 所持アバターの一覧・管理
- 🔔 **通知** — 招待・フレンドリクエストの監視・送受信・返信
- 👥 **ソーシャル** — フレンドログ、モデレーション、フレンドリスト
- 🧩 **ダッシュボード** — Feed / GameLog / Instance などのウィジェットでカスタムレイアウト
- 📊 **チャート** — インスタンス滞在アクティビティ、相互フレンドグラフ、ホットワールド
- 🗓️ **アクティビティヒートマップ** — 曜日×時間帯のオンライン傾向
- 📷 **スクリーンショットメタデータ** — 撮影画像へのワールド情報の埋め込み・閲覧
- 🖼️ **ギャラリー / 画像** — Unity を使わないアバター・ワールド画像のアップロードと詳細編集
- 🎭 **ステータスプリセット** — ステータス＋説明文の保存と即適用
- 🚨 **VRChat サーバー状態** — 障害・障害系アラートの表示
- 🎮 **Discord Rich Presence** — ワールドサムネイル・インスタンス情報・人数などの表示
- 🥽 **VR オーバーレイ** — 対応イベント・通知のライブフィード
- 🔌 **起動連携** — VRChat 起動時の外部アプリ自動起動
- 💀 **クラッシュ復帰** — VRChat クラッシュ時の自動再起動と最終インスタンスへの再参加
- ↔️ **データのエクスポート / インポート** — フレンド・アバター・Discord 名、メモ、お気に入りグループなど
- 🎨 **テーマ** — 外観のカスタマイズ（[Themes](https://github.com/vrcx-team/VRCX/wiki/Themes)）
